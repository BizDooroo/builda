# Rules Index

Open this file first for non-trivial work, then load only the rule files relevant to the change.

- `architecture.md`: roles, controller state, scheduling, execution lifecycle, recovery, and Web UI structure.
- `security.md`: script execution, authentication, credential handling, network exposure, and secret hygiene.
- `testing.md`: required checks and test coverage expectations.
- `workflow.md`: formatting, Git hygiene, ignore policy, and release-safe review steps.
- `deployment.md`: commit, push, tag, release, and user daemon expectations when asked to deploy.

Update the relevant rule file after completed work when a new durable lesson appears.
